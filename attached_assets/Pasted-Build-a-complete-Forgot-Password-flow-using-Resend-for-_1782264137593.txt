Build a complete Forgot Password flow using Resend for email delivery. Here is the full spec:
1. Server — new endpoints in server/routes.ts
POST /api/auth/forgot-password — public endpoint, no auth required:
Accept email in request body
Look up player by email in the database
If email not found, still return 200 with a generic message like "If that email exists you will receive a reset link" — never confirm or deny whether an email exists, this prevents email enumeration attacks
If found, generate a secure reset token using crypto.randomBytes(32).toString('hex')
Store the token and expiry (1 hour from now) in the database — add a password_reset_token and password_reset_expires column to the player_profiles table if they don't already exist, or use a separate password_reset_tokens table following existing schema conventions
Send the reset email via Resend using the existing Resend client already in the codebase — check how Resend is already initialized and use the same pattern. Email should come from noreply@chainggangpoker.com, subject "Reset your Chain Gang Poker password", and include a link to https://chainggangpoker.com/reset-password?token=TOKEN
Rate limit this endpoint to 3 requests per 15 minutes per IP to prevent abuse — follow existing rate limiter patterns
POST /api/auth/reset-password — public endpoint, no auth required:
Accept token and newPassword in request body
Look up the token in the database
If not found or expired, return 400 with "Invalid or expired reset link"
Validate newPassword is at least 8 characters
Hash the new password with bcrypt (same pattern as registration)
Update the player's password hash in the database
Invalidate the token immediately after use — delete it or mark it used
Return 200 with "Password reset successfully"
2. Database
Add password_reset_token (text, nullable) and password_reset_expires (timestamp, nullable) to player_profiles in shared/schema.ts, or create a separate password_reset_tokens table if that fits better with existing conventions. Run the migration.
3. Client — new page client/src/pages/ForgotPassword.tsx
Simple clean page matching CGP's dark aesthetic:
CGP logo or crown icon at top
"Forgot Password" title
Email input field
Submit button — "Send Reset Link"
On success show: "Check your email for a reset link" confirmation message
On error show the error message returned
Link back to login page
4. Client — new page client/src/pages/ResetPassword.tsx
Reads the token from the URL query parameter
New password input field
Confirm password input field — validate they match client-side before submitting
Submit button — "Reset Password"
On success: show "Password reset successfully" and redirect to login after 2 seconds
On error: show the error message
5. Routing
Add /forgot-password and /reset-password routes in the client router pointing to the new pages. Add a "Forgot password?" link on the existing login page pointing to /forgot-password.
6. Email template
The Resend email body should be clean HTML — dark background matching CGP brand, gold CGP crown or logo at top, clear heading "Reset Your Password", one sentence explaining the link expires in 1 hour, a prominent gold button linking to the reset URL, and a footer saying "If you didn't request this, ignore this email. Loyalty Never Leaves."
Run typecheck and full test suite after. Do not deploy until reviewed.
